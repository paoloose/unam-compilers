Ennuyeux Language Documentation

Comprehensive technical documentation for the Ennuyeux programming language. A robust, statically-typed, systems-level compiler project.

1. Paradigm, Design & Purpose

Ennuyeux is a statically-typed, compiled, and procedural systems programming language. It is fundamentally designed for academic rigor, speed, and strict memory semantics, adopting philosophies from modern languages like Rust while maintaining the low-level simplicity of C.

The primary purpose of Ennuyeux is to provide a robust compiler pipeline featuring Lexing, Parsing (LALR), Semantic Analysis (with deep type inference and checking), Mid-Level IR lowering (with optimizations like Constant Folding and Dead Code Elimination), and final bytecode generation targeting a custom FIS25 VM.

It acts as the capstone artifact for the UNAM Compilers Semester Project, demonstrating end-to-end language design, compiler implementation, and custom virtual machine execution with native graphics rendering capabilities.

2. Accepted Data Types & Type Inference

Ennuyeux enforces strict static typing. Variables are typed at compile-time, ensuring memory safety and deterministic execution. The supported primitive data types include:

  • int: 32-bit signed integers.
  • float: 64-bit floating point numbers.
  • bool: Boolean values representing true or false.
  • string: UTF-8 encoded text sequences.
  • arr: Dynamic memory handles used for fast array allocations.

The language features a highly intelligent Semantic Analyzer that provides Type Inference. You are not required to explicitly annotate types for variables; the compiler will automatically infer them based on the assigned expression.

// Variables with explicit typing
let iterations: int = 10000;

// Type inference: The compiler deduces these types automatically!
let is_active = true;
let pi_value = 3.14159;
let buffer = arr(1024);

3. Syntax & Reserved Words

Ennuyeux relies on a minimal, clean set of reserved keywords for defining control flow, variables, and structural constructs.

fn, let, if, else, loop, break, for, return, true, false, struct

Scopes are always defined by curly braces {} and statements must be terminated with a semicolon ;. Global variables can be declared at the top-level of any script and will be fully initialized before the application executes.

4. Functions & Return Inference

Functions are declared using the fn keyword, followed by the identifier and typed parameters. Ennuyeux supports Function Return Type Inference. The Semantic Analyzer evaluates the internal block and infers the return type automatically, meaning the -> type annotation is entirely optional.

// Function with explicit return type
fn multiply(x: int, y: int) -> int {
    return x * y;
}

// Function utilizing Return Type Inference
fn add(x: int, y: int) {
    return x + y; // Automatically inferred as an integer
}

// Implicit returns: the last expression in a block is returned
fn subtract(x: int, y: int) {
    x - y
}

5. Control Flow: Conditionals and Loops

Ennuyeux provides strict yet highly optimizable procedural control blocks. All conditional branches and iterative blocks are evaluated at compile-time to ensure deterministic behavior.

Conditionals (if / else)

Conditional branches evaluate boolean expressions.

let status = 200;
// Traditional if-else blocks
if status == 200 {
    print("OK");
} else {
    print("Error");
}

Iteration (loop, for, foreach)

Ennuyeux provides multiple loop constructs: loop for infinite loops, C-style for loops, and foreach loops for iterating over arrays.

// Infinite loops continue until explicitly broken
let counter = 0;
loop {
    if counter >= 10 { break; }
    counter = counter + 1;
};

// Traditional C-style for loop
for (let i = 0; i < 5; i = i + 1) {
    print(i);
}

// Foreach loops iterate seamlessly over arrays
let items = arr(3);
for item in items {
    print(item);
}

6. Operators

Ennuyeux provides a comprehensive set of operators for logic, arithmetic, and bitwise manipulation. All operators respect the type system and follow standard precedence rules.

Arithmetic Operators

  • +, -, *, /: Standard math operations.
  • %: Modulo operator for finding remainders.

Logical Operators

  • ==, !=: Equality and inequality checks.
  • <, >, <=, >=: Relational comparisons.
  • && (and), || (or), ! (not): Boolean logic evaluation.

Bitwise Operators

  • &, |, ^, ~: Bitwise AND, OR, XOR, and NOT operations.
  • <<, >>: Left and right bit shifts.

7. Data Structures (Structs & Arrays)

Ennuyeux goes beyond primitive types by supporting foundational memory data structures:

  • Arrays: Heap-allocated sequence of elements retrieved via idiomatic arr[index] bracket syntax. Array iteration is handled natively by the foreach loop.
  • Structs: Custom composite data types declared with the struct keyword. Under the hood, Ennuyeux elegantly compiles struct definitions and instantiations down to ordered heap arrays, making field access extremely fast while leveraging existing array infrastructure.
// Idiomatic array access
let my_array = arr(5);
my_array[0] = 10;
my_array[1] = 20;

// Declaring a composite struct
struct Vector2 {
    x: int,
    y: int
}

// Structs compile to arrays seamlessly
let v = Vector2 { x: 100, y: 200 };
print(v.y); // Outputs 200

8. Native Built-in Functions

The compiler integrates native hooks that map directly to the FIS25 VM operations. These provide I/O, memory allocation, and graphical execution without the need for an external standard library. These are used exactly like regular functions.

  • print(value): Outputs integers, floats, or strings to the standard console.
  • arr(size): Allocates a heap-based array and returns an arr handle.
  • pixel(x, y, color): Directly interfaces with the Raylib-powered VM to draw a pixel on a 64x64 grid.
  • sleep(ms): Pauses the VM execution for the specified milliseconds.
  • time(): Fetches the current UNIX epoch time in seconds.
  • key(code): Captures asynchronous keyboard input from the VM engine.
// Built-in functions example
print("Drawing a red pixel...");
let start = time();

// x, y, color (e.g. 1 for red)
pixel(32, 32, 1);
sleep(1000); // Wait for 1 second

9. Exhaustive Code Examples

The following examples demonstrate the Ennuyeux compiler's capacity for complex mathematical routines, recursive logic, and iteration. All snippets are fully validated in the compiler's tournament test suite.

Collatz Conjecture

// Computes the Collatz sequence for a given number
fn collatz(num: int) -> bool {
    let n: int = num;
    loop {
        // Verify if the number is even using modulo
        if n % 2 == 0 {
            n = n / 2;
        } else {
            n = n * 3 + 1;
        }
        // The sequence always converges to 1
        if n == 1 {
            print("success :3");
            return true;
        }
    };
    return false;
}

Extended Euclidean Algorithm

// Helper function for integer division using loops
fn idiv(a: int, b: int) -> int {
    let q = 0;
    let r = a;
    loop {
        if r < b {
            return q;
        }
        r = r - b;
        q = q + 1;
    };
    return q;
}

// Core extended euclidean algorithm
fn ext_euclid(a: int, b: int) -> int {
    let old_r = a; let r = b;
    let old_s = 1; let s = 0;
    let old_t = 0; let t = 1;
    
    loop {
        if r == 0 { break; }
        let quotient = idiv(old_r, r);
        
        let temp_r = old_r - quotient * r;
        old_r = r; r = temp_r;
        
        let temp_s = old_s - quotient * s;
        old_s s; s = temp_s;
        
        let temp_t = old_t - quotient * t;
        old_t = t; t = temp_t;
    };
    print("GCD:"); print(old_r);
    return old_r;
}

Monte Carlo Pi Approximation (With Global Variables)

// Top level variables are evaluated globally before main runs
let CONST = 2147483647;

fn mc_pi(iterations: int) -> float {
    let inside = 0;
    let seed = 12345;
    let i = 0;
    
    loop {
        if i >= iterations { break; }
        
        // Floating point parsing and precision checks
        seed = (seed * 16807) % CONST;
        let x = (seed % 1000) / 1000.0;
        
        seed = (seed * 16807) % CONST;
        let y = (seed % 1000) / 1000.0;
        
        if (x * x + y * y) <= 1.0 {
            inside = inside + 1;
        }
        i = i + 1;
    };
    return (inside * 4.0) / iterations;
}

Prime Number Calculation

fn is_prime(n: int) -> bool {
    if n <= 1 {
        return false;
    }
    let i = 2;
    loop {
        // Conditionals automatically infer boolean returns
        if i * i > n {
            return true;
        }
        if n % i == 0 {
            return false;
        }
        i = i + 1;
    };
    return false;
}

// Kaprekar sequence generator
fn kaprekar(n: int) -> int {
    let steps = 0;
    let current = n;

        // The Kaprekar constant

            return steps;
        }

            return -1;
